# FrigoScan

Application web installable (iPhone et Android) qui suit la date limite des produits frais.

Idée de Louis Goemaere.

- Scan en direct par la caméra : EAN-13, QR GS1 Digital Link, GS1 DataMatrix, GS1-128.
- Lecture de la date limite quand elle est dans le code (identifiants GS1 17 et 15).
- Frigo virtuel, rappels exportés vers le calendrier du téléphone (fichier .ics avec alarme) ou Google Agenda.
- Optionnel : avec une clé API Claude, lecture de la date sur la photo de l'emballage et recettes.
- Onglet Démo : passage en caisse simulé et étiquettes de test.

## Installer

- iPhone : ouvrir https://greggoem.github.io/frigoscan/ dans Safari, Partager, « Sur l'écran d'accueil ».
- Android : ouvrir le lien dans Chrome, menu, « Installer l'application ».

Les données restent sur le téléphone (stockage du navigateur).
