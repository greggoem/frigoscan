    Étiquettes de test

    Affichez-les sur un autre écran et scannez-les avec l'onglet Scanner. Les dates partent d'aujourd'hui.

    Trois niveaux

    Niveau 1 · partout, aujourd'hui

    Code-barres + date lue sur l'emballage

    L'EAN-13 identifie le produit, pas le paquet. La date vient de la photo, confirmée par le client.

    Niveau 2 · produits avec QR GS1

    Un scan, la date est dans le code

    GTIN + lot + date limite (identifiant 17). Étiquettes boucherie/traiteur, puis Sunrise 2027.

    Niveau 3 · ce qu'on propose à l'enseigne

    Zéro scan : la caisse remplit le frigo

    Carte de fidélité + ticket numérique avec la date de chaque produit frais.

    FrigoScan

    Réglages

    Rappels

    Le bouton « Rappels » du frigo crée les alarmes dans le calendrier du téléphone. Ajoutez-les après chaque course.

    Intelligence artificielle

    Optionnel. Avec une clé API Claude, l'app lit la date sur la photo de l'emballage et propose des recettes. La clé reste sur ce téléphone ; chaque demande coûte quelques centimes sur votre compte Anthropic.

    Données

    Le frigo est enregistré sur ce téléphone uniquement. Chaque membre de la famille a son propre frigo.

    Installer l'app

    iPhone : ouvrir dans Safari, bouton Partager, « Sur l'écran d'accueil ».
    Android : ouvrir dans Chrome, menu ⋮, « Installer l'application ».
